# 🧪 Helioscend: a 15-minute playtest for someone who has never seen the game

CrazyGames asks that **someone other than the developer** plays the game before it is submitted. Give this page to a
friend. Don't help them or explain anything: watch where they hesitate, and write it down.

## Setup
- **Desktop:** Chrome, a fresh incognito window (so there is no old save), at a normal window size.
- **Phone (if you can):** any phone, the browser in a private tab. Try portrait, then turn it sideways.
- Open the game the way you will ship it: run `py -m http.server 8080` (Windows) or `python3 -m http.server 8080`
  in the repo root and open `http://localhost:8080/starward3d/dist/crazygames/` (the CrazyGames build), or use the
  Developer Portal's QA tool / Preview after uploading the zip.

## What the tester does (no instructions given)
1. Start the game and play the first minute exactly as they would.
2. Keep playing for about 15 minutes: follow whatever the game suggests.

## What you write down
| Check | ✔ / ✘ and notes |
|---|---|
| The game was playable within 20 seconds |  |
| Without being told, they knew what to do in the first minute (the hand and the goal card) |  |
| They collected the bubbles, upgraded Mission Control and built the Research Center |  |
| They understood what the game is about (grow a space programme to the stars) |  |
| They found and used Build, Research and the goal card's "Show me →" |  |
| They claimed at least two goal rewards |  |
| Anything they tapped that did nothing, or that confused them |  |
| Any text too small to read, anything cut off the screen |  |
| Sound worked (after the first tap); the mute setting worked |  |
| Did the music feel good? Did they notice the base sounds when zoomed in (hammering, mining, wind)? |  |
| Did they notice the Standby board (idle drones, lab idle) and use it? |  |
| Did a Happening turn up (after about 6 minutes), and did they take it? |  |
| Did they notice the rank badge filling up, and enjoy the rank-up and its patch? |  |
| Did they try tapping bare ground? Was the plot card clear (what the plot is, what is under that spot)? |  |
| Did they find Explore and send a survey team? Could they see when it would finish? |  |
| Did they open the 📜 Logbook or try 📷 Photo mode? |  |
| On the phone: dragging pans, pinching zooms, tapping selects, both orientations usable |  |
| Any error, freeze or blank screen |  |
| Would they come back tomorrow? Why or why not? |  |

## After the test
- Close the tab, open the game again: the base should be exactly as they left it, with resources gathered while away.
- Settings → Start over resets everything for the next tester.
